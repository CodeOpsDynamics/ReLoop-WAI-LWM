# ReLoop: AI-Enabled Reverse Logistics for Corporate IT-Asset and E-Waste Recovery in India

**WAI Project | Logistics & Warehousing Management (Term V) | IIM Ranchi EMBA 2025-27**
**Author:** Himanshu Rai | **Faculty:** Prof. Krishna Kumar Dadsena

## Question
How should a corporate IT-asset-disposition (ITAD) network serving BFSI / GCC clients in 12 Indian cities be
redesigned, and what AI capabilities are needed, so that more value is recovered and less e-waste travels
1,400+ km to the UP-Uttarakhand-Haryana processing belt?

## Data disclosure
* **Real:** CPCB recycler registry (411 units, Aug 2026); Lok Sabha USQ 983 (2020) and 2458 (2021); TRAI ICT density (JES 2025-26, Table 9.8); Census 2011; CPCB national generation & formal processing FY18-FY25; state-wise processing and registered
  recyclers FY24-FY25 (PIB releases 1943201, 1941054, 2147876).
* **Proxy:** state generation = TRAI internet density x Census population; GSDP share used only as a robustness check (rank correlation 0.99). (CPCB does not publish
  state generation). Verify against RBI *Handbook of Statistics on Indian States* before reuse.
* **Synthetic (disclosed):** 12,000 IT-asset return records, 420 client pickup sites, 20 Pune pickup points,
  FMEA ratings come from an anonymous practitioner survey (data/raw/fmea_practitioner_survey_oct2026.csv); the earlier LLM-simulated panel is kept in code only as a benchmark. Synthetic files are frozen in the repo so results are identical on any machine.
* **Cost parameters** (freight rates, hub costs, asset values) are stated assumptions; see report Annex C and
  sensitivity table `t04_sensitivity.csv`.
